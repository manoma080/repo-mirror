# One-time draft binding

`.github/workflows/bind-approved-draft.yml` is a manually dispatched, input-free operation for draft 437729977 only. It checks the fixed Forgejo source, destination owner/repository and description, release identity and metadata, both complete asset lists and destination digests, and downloads and hashes both source PRX files. It then rechecks the snapshots and writes only the authenticated recovery marker to the draft body. It immediately reads back the release, checks preservation and verifies the signature with the production reader. A rerun with exactly the expected marker is a no-op. The normal mirror workflow is a separate action; this tool does not publish or transfer assets.

Run only from the management repository's default branch after reviewing and deploying this code; it requires the existing `MIRROR_OWNER`, `MIRROR_APP_ID`, `MIRROR_APP_PRIVATE_KEY`, and `MIRROR_TIMESTAMP_SECRET` configuration. It shares the `repository-mirror` concurrency group with the normal mirror. Wait for it to succeed before starting normal mirror publication; GitHub Actions can replace an already pending run in the same group.

**This is not an atomic compare-and-swap.** GitHub's release PATCH has no enforced precondition here. An external editor or other process can change the release or assets between the final GET and PATCH despite the shared Actions concurrency group. The approval assumes no such human edits and explicitly accepts that unavoidable race. Readback detects many changes but cannot prevent or reverse an overwritten concurrent body edit. An ambiguous PATCH error or any readback failure requires manual inspection before rerunning; the tool does not automatically retry the PATCH. Remove this one-time workflow/tool after the approved reconciliation is complete.
